Automat využívá pomocné čítače a příznaky:
\begin{itemize}
  \item ParenDepth - hloubka zanoření kulatých závorek (potlačuje generování $TOK\_NL$ a aktivuje kontrolu odsazení v $ST\_PAREN\_LINE$)
  \item commentDepth a commentNL – umožňuje rozpoznat vnořené blokové komentáře
  \item interpDepth, interpKind[] a interpInExpr[] - zásobník pro vnořené interpolované řetězce (s"...", s"""...""") a rozlišení, zda se automat nachází v textové části ($ST\_INTERP\_TEXT$), nebo uvnitř výrazu \$\{...\}
\end{itemize}
Jeden token může mít víc výstupů:
\begin{itemize}
    \item Jedno průchodové čtení může vygenerovat více tokenů najednou. K tomu slouží proměnné queued, hasQueued (pro TOK\_INDENT / TOK\_DEDENT / TOK\_NL před TOK\_EOF), interpQueued, hasInterpQueued, dotAfterNumber a resumeId 
\end{itemize}

Dvouvrstvá architektura readToken+getToken:
\begin{itemize}
    \item stavový automat readToken() neřeší porovnávání úrovní odsazení ani rušení duplicitních středníků, to obstarává nadřazená vrstva getToken() pomocí zásobníku odsazení indentStack
\end{itemize}
\begin{itemize}
    \item stavový automat readToken() neřeší porovnávání úrovní odsazení ani rušení duplicitních středníků, to obstarává nadřazená vrstva getToken() pomocí zásobníku odsazení indentStack
\end{itemize}

\section{Přehled modulů}
\begin{itemize}
    \item \texttt{scanner.c / scanner.h}: ...
    \item \texttt{parser.c / parser.h}: Parser je implementován metodou rekurzivního sestupu a udržuje si stav zpracování včetně následujícího tokenu. Přebírá tokeny ze scanneru, ověřuje očekávané tokeny, zjišťuje, zda patří do množiny Predict. Spouští analýzu celého programu s výstavbou AST.
    \item \texttt{precedence.c / precedence.h}: Implementuje precedenční syntaktickou analýzu pro výrazy pomocí zásobníku. Převádí vstupní tokeny na precedenční symboly, redukuje pravidla a zpracovává argumenty volání funkcí. Hlavní funkce inicializuje zásobník se zarážkou a v cyklu čte vstup podle precedenční tabulky, přičemž provádí posuny nebo redukce.
    \item \texttt{ast.c / ast.h}: Implementuje práci s abstraktním syntaktickým stromem (AST), ve kterém si překladač ukládá strukturu zpracovaného programu (výrazy, příkazy, funkce, větvení i cykly). Vytváří jednotlivé uzly a řadí je do spojových seznamů. Rekurzivní uvolňování celé struktury.
    \item \texttt{symtable.c / symtable.h}: Implementace tabulky symbolů postavená na \texttt{hashtable} a řešená formou zásobníku. Při inicializaci se automaticky vytvoří globální rozsah (\emph{scope}), do kterého se předplní vestavěné funkce. Podporuje základní operace, jako je vložení nového rozsahu na zásobník, vkládání symbolů a vyprázdnění zásobníku.
    \item \texttt{hashtable.c / hashtable.h}: Obecná implementace hashovací tabulky s řešením kolizí pomocí lineárního sondování (linear probing) a podporou základních operací (vkládání, vyhledávání, mazání, uvolnění paměti); slouží jako datová struktura zejména pro tabulku symbolů
    \item \texttt{semantic.c / semantic.h}: Sémantická analýza, implementovaná tak, aby kontrolovala funkce, rozsahy platnosti, příkazy a výrazy.
    \item \texttt{codegen.c / codegen.h}: Vygeneruje uživatelský program a vestavěné funkce, volání funkcí implementuje s předáváním na zásobníků, který používá také pro vyhodnocování výrazů
\end{itemize}
